# prosemirror-excel-paste

Плагин ProseMirror, который превращает таблицы, скопированные из Excel (Windows/Mac/Online), Google Sheets, LibreOffice Calc и Numbers, в нормальные таблицы `prosemirror-tables`. Стили сохраняются. Ещё он умеет вставлять **сами файлы** `.xlsx`/`.csv` из буфера обмена. Без зависимостей, кроме самого ProseMirror: ZIP, inflate, разбор SpreadsheetML и форматы чисел Excel написаны внутри.

Плагин только **нормализует HTML** из буфера обмена (`transformPastedHTML`). Остальное делают парсер вашей схемы и `prosemirror-tables`. Поэтому:

- курсор вне таблицы → вставляется новая таблица;
- курсор в ячейке → скопированный диапазон (в том числе **часть таблицы Excel**) вставляется в существующую таблицу, начиная с этой ячейки; при нехватке места таблица растёт;
- выделены ячейки (`CellSelection`) → диапазон заполняется скопированным, при необходимости с повторением;
- одна скопированная ячейка → вставляется как обычный текст со стилями (меняется опцией `singleCell`).

## Подключение

```js
import { Schema } from 'prosemirror-model'
import { schema as basic } from 'prosemirror-schema-basic'
import { tableNodes, tableEditing } from 'prosemirror-tables'
import { excelPaste, excelCellAttributes, excelMarks } from 'prosemirror-excel-paste'

const schema = new Schema({
  nodes: basic.spec.nodes.append(tableNodes({
    tableGroup: 'block',
    cellContent: 'block+',
    cellAttributes: excelCellAttributes   // background, textAlign, verticalAlign, border*
  })),
  marks: basic.spec.marks.append(excelMarks) // underline, strikethrough, sub/superscript, textColor, fontSize, fontFamily
})

const plugins = [
  excelPaste(),   // до tableEditing(): иначе вставка файла в выделенные ячейки уйдёт в tableEditing
  tableEditing(),
  // ...
]
```

`strong`, `em`, `link` и `hard_break` берутся из `prosemirror-schema-basic`. Если в вашей схеме свои марки или атрибуты ячеек, `excelCellAttributes` и `excelMarks` можно не подключать. Плагин выдаёт обычный HTML, и ваши правила `parseDOM` его разберут:

| Что | HTML на выходе |
|---|---|
| ячейка | `<td colspan rowspan data-colwidth="120,96" style="background-color; text-align; vertical-align; border-top/right/bottom/left">` |
| текст | `<strong> <em> <u> <s> <sub> <sup> <a href> <br>` и `<span style="color; font-size; font-family">` |

## Опции

```js
excelPaste({
  sources: ['excel', 'google', 'libreoffice', 'numbers'], // + 'generic' — любые HTML-таблицы
  singleCell: 'inline',     // 'table' — вставлять 1×1 как таблицу
  lineBreaks: 'br',         // 'paragraph' — Alt+Enter в ячейке → отдельные абзацы
  columnWidths: true,       // data-colwidth из ширин столбцов (px)
  skipHidden: true,         // выкидывать скрытые строки/столбцы
  tsv: false,               // true — plain text с табами → таблица (Ctrl+Shift+V не затрагивается)
  styles: { fontFamily: false, fontSize: false }, // отключить отдельные стили; по умолчанию всё true
  files: {                  // вставка файлов; files: false — выключить
    maxCells: 50000,        // большие листы обрезаются по строкам
    conditionalFormatting: true,
    locale: undefined,      // локаль для чисел/дат и кодовой страницы CSV; по умолчанию браузерная
    encoding: undefined,    // принудительная кодировка CSV, например 'windows-1251'
    onLoadStart(file) {},   // чтение асинхронное — можно показать индикатор
    onLoad(file, sheet) {},  // sheet = { name, model }
    onError(error, file) {} // без него ошибка пишется в console.warn, документ не меняется
  }
})
```

Без плагина тоже можно: `transformSpreadsheetHTML(html, options)` возвращает строку, а `parseSpreadsheetHTML(html)` — модель таблицы (`rows → cells → paragraphs → runs`), если нужно собрать узлы самостоятельно.

## Вставка файлов

Если в Finder или Проводнике скопировать файл и нажать Ctrl+V в редакторе, браузер передаёт его в `clipboardData.files`. Плагин читает файл асинхронно и вставляет его тем же путём, что и обычную вставку. Поэтому файл в таблицу под курсором встаёт так же, как диапазон из Excel. Изображения в буфере игнорируются: Excel кладёт туда PNG-снимок диапазона рядом с HTML.

| Формат | Что читается |
|---|---|
| `.xlsx` `.xlsm` `.xltx` `.xltm` | **только первый лист** (первый видимый по порядку вкладок); остальные листы не распаковываются и не разбираются; значения с форматами чисел и дат Excel; стили ячеек и шрифтов, цвета темы с оттенками и индексированная палитра; rich text; объединения; скрытые строки и столбцы; ширины столбцов; внешние ссылки; условное форматирование |
| `.csv` `.tsv` | кодировка: BOM → UTF-8 → `windows-1251`, если похоже на кириллицу или локаль ru/uk/…, иначе `windows-1252`; разделитель `,` `;` `\t` `\|` определяется автоматически, учитывается `sep=;` от Excel; поля в кавычках с переносами; числа выравниваются вправо |

**Форматы чисел и дат** — своя реализация кодов формата Excel: секции `плюс;минус;ноль;текст`, условия `[>=1000]`, цвета `[Red]`, литералы и `\`, `_`/`*`, валюты `[$€-407]`, проценты, масштабирование `#,##0,`, экспонента, дроби `# ?/?`, даты и время (включая `[h]:mm:ss`, AM/PM, доли секунд), ошибку високосного 1900 года и систему дат 1904. Разделители, названия месяцев и дней недели, `ИСТИНА`/`ЛОЖЬ` и встроенный «короткий формат даты» берутся из локали, как это делает сам Excel.

**Условное форматирование** вычисляется для правил: `cellIs` (сравнения с числами, строками и ссылками на ячейки), «текст содержит / начинается / заканчивается», пустые ячейки и ошибки, первые/последние N и N%, выше/ниже среднего, повторяющиеся и уникальные значения, двух- и трёхцветные шкалы. Учитываются приоритеты и `stopIfTrue`. Правила с формулами (`expression`), гистограммы и наборы значков **не** вычисляются: для них нужен вычислитель формул.

**Формулы** не пересчитываются: берётся последний результат, который Excel сохранил в файле. Если файл записан программой, которая не сохраняет результаты, ячейка окажется пустой.

Для своих сценариев (выбор файла через `<input type=file>`, drag-and-drop) есть `pasteSpreadsheetFile(view, file, options)` и `readSpreadsheetFile(file, options)`. Последняя возвращает `{ name, model }` первого листа без вставки (или `null`, если данных нет).

## Что поддерживается

**Стили ячеек, столбцов и таблицы.** Классы Excel (`.xl65`), `mso-style-parent` (именованные стили вроде «Плохой»), `td`-правила и стили, заданные прямо в ячейках (inline), сводятся в итоговые стили каждой ячейки: заливка, выравнивание по горизонтали и вертикали, границы по сторонам. Толщины Excel переводятся в пиксели: `.5pt` → 1px, `1pt` → 2px, `1.5pt` → 3px. Стили `hairline` и `dot-dash` заменяются ближайшими CSS-стилями. Ширины столбцов берутся из `<col>`/`<colgroup>` с учётом `span` и сохраняются как `colwidth` из prosemirror-tables. Объединения сохраняются (`colspan`/`rowspan`).

**Rich text.** Если в ячейке Excel текст оформлен по-разному, он приходит частями `<font class="fontN">`, и каждая часть получает свои марки. Шрифт книги по умолчанию (Calibri 11pt чёрный в Excel, шрифт таблицы в Google Sheets) **не** переносится: в марки попадает только то, что от него отличается. Иначе каждая вставка тянула бы за собой «Calibri 11pt».

**Условное форматирование.** Применённые цвета переносятся, если Excel положил их в буфер как обычные стили ячейки (это стоит проверить в демо на ваших файлах). Сами *правила* в буфер обмена не попадают.

**Проверка данных (Data Validation).** Через буфер обмена не передаётся ни одним приложением. В `.xlsx` она есть, но в ячейке таблицы ProseMirror ей нечем быть, поэтому при вставке файла она пропускается.

**Исправление особенностей разных приложений:**
- Excel: `colspan` + `mso-ignore:colspan` — это не объединение, а текст, вылезающий в соседние ячейки; такая ячейка разбивается обратно;
- Excel: `text-align:general` + `align=right` у чисел → числа выравниваются вправо, как в Excel;
- Excel: системные цвета (`windowtext`), переносы строк внутри исходного HTML, `<br style='mso-data-placement:same-cell'>`, ячейки только с `&nbsp;`, `<o:p>`;
- Excel: скрытые строки и столбцы, которые Excel копирует вместе с диапазоном;
- Google Sheets: CSS-правило `td {border:1px solid #ccc}` — это сетка листа, а не границы, оно игнорируется;
- LibreOffice: `bgcolor`, `<font color face size>`, `<colgroup width span>`, скрытые примечания `<comment>`;
- рваные строки и частично попавшие в выделение объединения дополняются до прямоугольной таблицы;
- заголовок `Version:0.9 StartHTML:…` формата Windows CF_HTML, если браузер его не убрал;
- безопасность: пропускаются только ссылки `http(s)`/`mailto`/`tel`; цвета, границы и шрифты проходят через белые списки; результат строится через DOM, а не склейкой строк.

**Локали.** Excel кладёт в буфер уже отформатированный текст (`1 234,50 ₽`, `14.10.2026`), и он вставляется как есть, без переформатирования. Кириллица, CJK и другие алфавиты в тексте и названиях шрифтов сохраняются. TSV разбирается с учётом кавычек и переносов внутри полей, как его пишет Excel.

## Чего нет (по сравнению с SheetJS)

- двоичные `.xls` (BIFF8), `.xlsb`, `.ods`, `.numbers`: такой файл перехватывается, и `onError` получает понятную ошибку «save it as .xlsx» (имя файла в документ не вставляется);
- пересчёт формул, правила условного форматирования с формулами, гистограммы, наборы значков;
- запись и экспорт обратно в Excel;
- зашифрованные книги и ZIP64 (файлы больше 4 ГБ).

## Разработка

```sh
npm test       # vitest + jsdom, включая вставку через EditorView
npm run fixtures    # пересобрать тестовые файлы в test/fixtures из test/fixtures.js
npm run demo        # демо на чистом JS
npm run demo:react  # демо на React (http://localhost:5174): переключатели опций, буфер, модель, документ PM
```

Тестовые фрагменты HTML в `test/fixtures` воспроизведены по формату приложений, а не сняты с реального буфера обмена.

Файлы `.xlsx`/`.csv`/`.tsv` в `test/fixtures` генерируются (`npm run fixtures`) из описаний в `test/fixtures.js` с помощью тестового писателя `test/xlsx-writer.js`. Тест проверяет, что файлы на диске совпадают с описаниями. Любой из них можно скопировать в Finder и вставить в демо.

| Файл | Что проверяет |
|---|---|
| `sample.xlsx` | XML написан вручную «как у Excel»: стили, rich text, объединения, скрытые строки и столбцы, условное форматирование, ссылки |
| `formats.xlsx` | 32 формата чисел и дат; колонка C — что показывает Excel |
| `rich-text.xlsx` | части текста, индексы, подчёркивание, зачёркивание, цвета темы, многострочный текст, эмодзи, арабский, иврит, китайский, японский, экранирование |
| `merges.xlsx` | вложенные объединения, объединения через скрытый столбец и скрытую строку |
| `conditional.xlsx` | по столбцу на каждый тип правила, приоритеты и `stopIfTrue`, пропуск правила-формулы |
| `theme-colors.xlsx`, `custom-theme.xlsx` | оттенки темы (сверены с эталонными цветами Office), индексированная палитра, ARGB, своя тема |
| `date1904.xlsx` | система дат 1904 |
| `offset.xlsx`, `no-refs.xlsx`, `minimal.xlsx`, `prefixed.xlsx`, `stored.xlsx` | данные далеко от A1, ячейки без `r=`, книга без стилей и темы, префикс `x:`, ZIP без сжатия |
| `formulas.xlsx`, `hyperlinks.xlsx` | сохранённые результаты формул всех типов, ячейки дат `t="d"`; безопасные и опасные ссылки |
| `multi-sheet.xlsx`, `hidden-first.xlsx`, `empty-first.xlsx` | читается только первый (видимый) лист |
| `big.xlsx` | 60 000 ячеек — обрезка по `maxCells` |
| `broken-truncated.xlsx`, `not-a-workbook.xlsx`, `legacy.xls` | понятные ошибки |
| `sample-cp1251.csv`, `cp1252-western.csv`, `utf8-bom.csv`, `utf16le.tsv`, `sep-hint.csv` | кодировки и разделители | Чтобы добавить настоящий фрагмент, вставьте диапазон в демо, нажмите «Скачать .html», положите файл в `test/fixtures` и напишите для него тест.
